# Роботы на карте Minecraft

Симуляция искусственной жизни в браузере: маленькие роботы-утки живут на блочной карте, сами учатся ходить, прыгать, есть яблоки с деревьев, копать, строить, крафтить и говорить на собственном языке.

Открыть: `index.html` (работает без интернета и без сервера) или страница GitHub Pages этого репозитория.

## Что внутри
- **Мир** — карта из Minecraft-экспорта (Mineways), очищенная до грунта: трава, деревья с яблоками, вода с волнами и бликами, смена дня и ночи, времена года, зомби по ночам.
- **Роботы как норны из Creatures** — 12 драйвов (голод, жажда, боль, холод, страх, скука…), химия (адреналин, эндорфин, награда, антигены), физическое и психическое здоровье, стадии жизни, 17 генов.
- **Мозг размером с мозг муравья** — около 250 000 нейронов в 10 отделах (пропорции как у рабочего муравья: маленькие глаза, большие антеннальные доли и огромные грибовидные тела) с разреженной активностью; обучение дофамином в грибовидных телах и растущая решающая сеть.
- **Колония как у муравьёв** — у каждой стоянки матка (только она откладывает яйца), остальные с рождения получают должность: солдаты, строители (роют подземное гнездо со сводами, ходом и кладовой), фуражиры (носят еду на склад), няньки, разведчики. Ходят по тропам с поиском пути по рельефу.
- **Режим наблюдателя под землёй** — кнопка «Под землёй» (или U) срезает мир по высоте, PageUp/PageDown двигают срез; при слежении за роботом срез идёт за ним.
- **Обучение без подсказок** — копать, рубить, носить, ставить блоки, крафтить по рецептам Minecraft, драться и прыгать никто не учит: навыки растут практикой, польза — из драйвов. Знания передаются детям и соседям (подражание).
- **Язык** — из выученных букв алфавита роботы составляют слоги и слова; общий словарь складывается «игрой в имена».
- **Автосохранение** — мир сохраняется в браузере (IndexedDB) раз в минуту и при закрытии вкладки.

Текстуры блоков нарисованы заново для этого проекта (процедурно, 16×16) — ассеты Minecraft не используются. Рельеф карты взят из собственного мира автора, экспортированного через Mineways. Проект не связан с Mojang и Microsoft.

## Управление
ЛКМ — вращать · ПКМ / колёсико / Shift — двигать · колесо — зум к курсору · WASD — ехать · Q/E — поворот · R/F — ближе/дальше · двойной клик — перелететь (по роботу — следить) · Home — общий вид · пробел — пауза.

Выделите робота, чтобы открыть его наборы: Рука (погладить / шлёпнуть), здоровье, химия, сумка, навыки, генетика, проекция мозга.
